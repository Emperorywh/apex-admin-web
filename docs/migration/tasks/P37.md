## 接口缺口

- 无新增 G 编号。G15（统计口径/时区）页面侧落实：秒单位按 OpenAPI 字段注释；时区为部署时区（页面时间筛选为部署时区墙钟 `yyyy-MM-dd HH:mm:ss`，与旧实现等价，不发时区字符串）；利用率「分母不乘车辆数可超 100%」与「平均分母=车辆数、未出现状态按 0 参与」口径已在四语言「·计算方式」显式说明（公式真实数据复核归 V01，P33 同口径）。
- G10（int64）：totalDurationSeconds/vehicleCount 按 JSON number 承载（P21/P33/P36 同口径），本页数量级（≤10^8 秒）无精度风险。
- 对照发现（非缺口）：agvExecutingTimeStatistics 对 byHour=true 且跨度>24h 仍返回 code=200（后端未强制「不能超过 24 小时」的文档约束）；前端拦截是唯一防线（旧实现同为前端校验，等价保留）。
