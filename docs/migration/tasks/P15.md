## 3. 联验环境教训（沉淀 AGENTS 第 5 节候选）
- **IAB 垫片注入后自检必要性**：首次注入的 rAF/RO 垫片在登录导航后失效（`window.ResizeObserver` 非 ShimRO、`window.__p15Shim` 丢失，同文档 `window.__p15xhr` hook 却存活——失效机理未完全定位），症状为「表头正常渲染、total=1 但 tbody 0 行」。**定版手法：每次注入后立即自检 `String(window.ResizeObserver).includes('__cb')`，失败即重注入**；改良垫片带实例注册表（window.__p15ROs + __p15FireAll 手动全量派发入口）。重挂载依赖 Dock 菜单 SPA 导航（主菜单按钮需 hover 序列 pointerover/mouseover/mouseenter/mousemove 展开，click 对子级 menuitem 生效需 pointerdown/mouseup/click 序列）。
- **Modal 关闭动画卡住为 IAB 伪象**：提交成功后弹窗 DOM 卡 `ant-zoom-leave-start`（antd motion 依赖冻结管线的动画帧），wrap display:block 但业务链路（POST/toast/reset/onSucceeded）全部正常完成；诊断时以 XHR 请求与 React 状态为准，不误判为应用缺陷。
- **「恢复默认」清空钉位偏好的验证副作用**（P14 第⑧条同款再实证）：列偏好验证中「恢复默认→应用」会保存空 columnPinning、覆盖代码 defaultPinning（用户偏好覆盖代码默认语义正确），后续截图前需清偏好键（apex-table:columns[…device-auto-door:main]）+重挂载让 defaultPinning 重新生效，再以 data-pinned 属性断言。
