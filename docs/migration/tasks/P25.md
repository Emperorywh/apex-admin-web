## 5. 等价迁移差异登记

1. **停滞检测不落地**：旧实现自研 XHR 封装含 60s 连接/上传停滞自动中止；新架构统一 axios 通道（无停滞事件），保留取消入口+网络错误兜底呈现。旧 SPEC 的用户决策（真实进度/可取消/100% 后等待/不自动重试/失败留输入/严格判定）全部保留。
2. **下载侧从伪进度升级为真实进度**：旧 FakeProgressModal 是任务卡点名移除项，新弹窗仅在已知总字节时显百分比（本环境实测响应无 content-length → 走马灯+已接收 MB，DoD 9 纪律）。
3. **删除/回滚/重启确认统一升级 confirmCommand**（旧 Popconfirm 一问/Modal.confirm 两问 → 对象+影响+提交≠完成附注+danger，DoD 8，P04–P23 同款）。
4. **无手动刷新按钮**（按钮纪律）：删除/上传成功后自动 reload；重启/回滚经重新登录回跳自动查询。旧「刷新」按钮不迁移。
5. **未知枚举/空值**：版本 type 未知值灰色 Tag 显示协议原值；Git标签列本环境真实数据为空→留白（空值纪律）；时间列 displayDateTime 秒级展示转换。
