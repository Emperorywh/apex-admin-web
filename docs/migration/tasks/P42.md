## 交付内容

1. **NotFound 等价迁移**（NotFound.tsx + .module.css 重写）：antd Result 404 等价呈现；副标题迁移旧 key「抱歉，您访问的页面不存在」；恢复动作按真实登录态区分——已登录显示旧 key「首页」按钮（`resolveLandingPath` 落点导航，replace 不留历史），未登录（公开 /404 直达）显示「去登录」（replace 到登录页、**不携带未知 URL 回跳参数**——`resolveSafeRedirectPath` 会拒绝未知路径，带了也无效）。旧按钮固定跳 `/over-look`：该地址在新系统为暂缓说明页（H01），不作为恢复落点复刻，落点规则才是旧「回到可用页」语义的等价实现。
2. **双挂载场景统一**：显式 `/404`（公开，BlankLayout 独立渲染）与受保护根内 `*` 兜底（BasicLayout 页签区渲染，守卫保证已登录）共用同一组件；玻璃反馈面板（`--app-glass-window`/`--app-glass-filter`/`--app-radius-window`/`--app-window-shadow`，P41 同因同解——壁纸固定照片深色反白不可读）在两种挂载下都提供两主题衬底。
3. **/500（ServerError）核对收口**：恢复动作同样按登录态区分（重新加载 + 已登录「首页」落点 / 未登录「去登录」防御分支）；移除固定跳 `/over-look` 的旧落点。布局内渲染（工作区玻璃窗口已衬底）不另加面板。
4. **路由错误边界（RouterErrorBoundary）核对收口**：顶层 `errorElement`（loader/guard 抛错、顶层 chunk 加载失败）——文案显式指定 `error` 命名空间；恢复按钮按渲染时会话快照区分（已登录 `assign(resolveLandingPath(auth))` / 未登录 `assign(/login)`）；补充玻璃面板（errorElement 替换整棵路由树渲染，无布局衬底）。
5. **页面错误边界（PageErrorBoundary）核对收口**：文案显式 `ns:'error'`；布局内渲染（页签区）不另加面板；`error.message` 为技术诊断信息保留（非会话信息）。
6. **error 分片列入基座常载**：`BASE_NAMESPACES` 从 `['common','menu']` 扩为 `['common','menu','error']`——错误兜底（404/500/两级边界）可随时出现在任意路由（包括未声明页面命名空间的公开页与类组件直读 `i18next.t` 的错误边界），随基座加载保证文案必然就绪。**修复缺陷**：原 RouterErrorBoundary/PageErrorBoundary 的 `i18next.t()` 走 defaultNS=common，而「页面加载失败/页面渲染出错/重试」等 key 只在 error 分片——非中文语言下错误边界会回退显示中文 key（I05/I06 违规），已由 ns 显式化+基座常载修复。
7. **五语言**：error 分片四语言补「抱歉，您访问的页面不存在」「首页」「去登录」；en 沿用旧系统真译（Sorry, the page you visited does not exist / Home / Go to Login）；zh-TW/ja-JP/ko-KR 旧资源为简中回退，按 B1 基线交付真实译文（繁中「造訪/登入」台湾用语；去登录与 access-denied 分片同术语）；移除不再消费的模板 key「页面不存在或已被移动」「返回工作台」（四语言同步，无死资源）。
8. **公共文件改动**：删除 `src/constants/route.constants.ts`（`FALLBACK_PATH` 唯一三个消费者 RouterErrorBoundary/NotFound/ServerError 全部改落点规则，确认全仓库无残留引用后删除，含 `/over-look` 锚点注释）；`src/i18n/i18n.ts`（BASE_NAMESPACES 扩展）。均经 typecheck/结构检查/全量构建证实无消费者破坏。

## 登记的限制（非缺口）

1. **错误边界运行时呈现未浏览器实测**：RouterErrorBoundary（顶层 loader/guard 抛错、chunk 加载失败）与 PageErrorBoundary（页面渲染异常）无自然触发场景，按「不注入临时缺陷代码」纪律不做人工构造；其正确性证据为——ns 显式化 + error 分片基座常载（资源必然就绪，typecheck 强制）+ 四语言 key 齐备性静态核对 + 类组件渲染逻辑代码审查。恢复动作与 /500 同模式（已实测）。
2. **深色截图管线瞬时黑屏**：联验中出现 3 次「DOM 内容完整但截图全黑/面板空白」的捕获帧（重试即恢复，页面 DOM/计算样式始终正常）；非应用缺陷，截图工具瞬时问题，已用恢复后的成功截图为准。
3. **已登录访问 /login 不自动落点**：沿用 P01 交付行为（登录页渲染），回跳校验发生在登录提交时（T00.4/P01 已验），非本任务范围。
4. 「首页」落点按钮当前只能实测到「落点=/no-permission」分支（无已完成迁移业务页）；落点解析本身为 T00.4 已实证机制，可用业务页分支随 B2a 首个业务页交付后复核。
