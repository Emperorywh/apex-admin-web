## 5. 本轮沉淀（已同步 AGENTS.md 第 5 节）

- **垫片时序根因**：Apex 在 useLayoutEffect 中 `new ResizeObserver`（读 clientWidth/Height 置 measured）；IAB 冻结管线原生 RO 回调不派发 → dimensions 恒 {0,0}→canRender=false→tbody 0 行。垫片必须早于 Apex mount 才能被捕获：**reload 后注入必输**（模块缓存加速 mount）；**可靠手法 = 注入垫片后经真实菜单导航（Dock→子菜单项）触发组件卸载重挂载**，此时 Apex new 到的是垫片类，observe 即多点派发；手动全量派发（记录 (instance,target) 对的 `__p10FireAll`）可对**已挂载但 dimensions 未更新的表格**补救（fire 第二轮生效）；主题切换后 reload 黑帧以新页签整页载入规避（P09 已登记，本轮复证）；
- antd v6 Select DOM：`.ant-select > .ant-select-content + .ant-select-suffix`（v5 的 `.ant-select-selector` 不存在）；下拉打开=mousedown on `.ant-select-content`；选项选中=mousedown+mouseup+click；冻结管线下选项过滤用 native setter 写搜索 input；
- 主题三态菜单项在「长时间存活的文档」中 DOM 合成点击可能不生效（曾成功一次后失效）——**可靠路径 = 直写 persist:apex-admin:settings 的 theme + reload 走应用真实 rehydrate**（P09 主题三态下拉沉淀的补充）。
