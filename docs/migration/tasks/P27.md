## 1. 业务范围与操作映射（逐 operation）

| operation | method/path | 页面消费 | OpenAPI 核对 |
| --- | --- | --- | --- |
| 上传或覆盖 Logo | PUT /fms/v1/systemLogos/{placementKey}（multipart/form-data，字段 file） | 三张卡片上传按钮（按钮码控入口）→ 成功后品牌变更通知 | requestBody multipart `file` binary → ResultVoid |

## 5. 接口缺口与登记

- **契约实证（联验，非缺陷）**：systemLogos 接口族后端**完全无需认证**——无令牌
  PUT 亦受理 code=200；无令牌 GET file 对不存在资源返回 404（资源状态而非 1000000
  会话拒绝）。与「登录前可用的装饰资源」设计语义一致（登录页背景必须在未登录可达，
  T00.3 已实证 GET /systemLogos 无令牌 code=200）；前端入口仍由菜单码+三按钮码控
  制。登记 contracts 第 5 节品牌行。
- **后端不校验图片内容**：文本内容 + .png 后缀上传亦受理 code=200（浏览器标注的
  multipart part Content-Type=image/png 会被原样存储）。「伪图片」防线在展示层：
  Blob 元数据校验（isUsableImageBlob）+ img onError 兜底占位/回退，不伪装有图。
- 无「有配置无接口」缺口：旧页面仅图片配置一个 Tab，三展示位均有对应接口；
  **不新增通用设置 CRUD**（SPEC 纪律），G12 不适用本页。

## 6. 等价迁移差异登记

- 旧版上传后仅刷新本卡片预览；新版经品牌变更通知**全部已挂载消费者**（本页三卡 +
  顶栏 logo + favicon）即时重拉（任务卡「按约定使登录/外壳刷新真实资源」的落地）；
  登录背景在下次进入登录页时以新资源呈现（登录页挂载即拉取，本轮登出→登录页实证）；
- 拉到不可用内容（伪图片/非图片）：清空回退占位（旧版 antd Image onError→占位同
  语义）；**上传失败**保留原已确认资源（失败路径不调通知不重拉，A16）；
- accept 过滤 + beforeUpload 扩展名二次校验（防「所有文件」绕过，P08 同款；旧版仅
  accept 一层）；「仅支持 … 格式的文件」为本页新增防御文案（无旧译，四语言补译）；
- 上传不接页签 scope.signal、不登记传输管理器（小文件秒级完成，旧版同语义：
  axios 上传不随页面切换/卸载中止；A16 切页继续/取消边界条款针对传输管理器登记

- 品牌图是装饰性资源不是业务记录：无表格无列偏好无轮询（旧版即卡片网格）。

### 7.3 排查沉淀（AGENTS 第 5 节⑳）

「同轮 evaluate 第二次文件注入无效」最初疑似 imgFailed 重置缺陷，多轮复现后定位：
antd Upload 在 uploading 切换后 input DOM 引用变化，**测试脚本持旧引用 dispatch
change 不再触发**——每次注入前重新 querySelector input 即恢复。产品代码无缺陷；
教训：无头上传注入必须每次重查 input，且「时好时坏」先核对注入手法再怀疑产品代码。
