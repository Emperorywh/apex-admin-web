## 本轮（T00.3）交付物与证据

### 1. 请求层重写（`src/services/request/`，owner T00）

- **Result 解包**：HTTP 成功且业务 `code=200` 才进入成功分支，返回 `data`；不依赖 `message === 'success'`。非 Result 形状的 JSON 按 `CLIENT.MALFORMED_RESPONSE` 报错，不猜数据。
- **业务码常量**（`RESULT_CODES`）：`200` 成功、`1000000` 会话失效、`1001000` 未授权（旧代码证据，待真实复核）、`1000010` 登录失败。
- **会话失效收敛（单飞）**：1000000（或未预期的 HTTP 401）→ 清令牌 + 一次性 `message.warning` + 派发 `sessionExpired`，跳转由 BasicLayout 既有守卫统一处理；并发失效只处理一次，无重定向风暴；换新令牌自动复位。
- **取消静默**：AbortSignal 主动取消不报错、不判离线、不参与健康统计。
- **健康反馈**：有真实后端响应（含业务拒绝）= ok；无响应/HTML/网关级错误 = error；不得把业务拒绝当离线（规格 4.2）。
- **文件通道**：非 JSON content-type 响应原样透传 Blob，绝不套 Result 解包。
- **移除刷新重放**：`/auth/refresh` 单飞、`_retriedAfterRefresh`、401 重放逻辑全部删除（G01/G02）——后端无刷新协议，过期即重新登录。
- **认证与语言头**：`Authorization: Bearer <token>`（请求层单点）+ `Accept-Language`（i18n 初始化/切换时经 `setRequestLanguage` 同步）；请求层文案全部经 i18next 翻译（直接依赖 i18next 包，避免与 `@/i18n/i18n` 循环导入）。
- **类型**：`ResultDto<T>`、`BackendPageQuery`（pageNo/pageSize）、`BackendPageResult`（records/current/size/total/pages）、`ApiError.businessCode`；模板遗留类型（EntityStatus/PageQuery/PageResult）保留并标注，随 P03/P31/P32/P34 替换后删除。

### 2. 真实登录/登出（`src/services/auth/`）

- `login`：`POST /auth/authorize/login`，密码 MD5（spark-md5@3.0.2，auth.service 单点，G03 旧代码证据）；返回 `UserAuth` 一次性构建会话（token/activated/user/roles/permissions/permissionsTree），空字段回退诚实默认值。
- `logout`：`POST /auth/authorize/logout`（OpenAPI 已核实存在），尽力通知，失败继续本地登出。
- **删除**：直通登录（伪造 super_admin）、`loadSession`（`/users/me`）、旧 `/auth/logout` 路径；`profile.service`（`/users/me` 读写）整目录删除。
- `authBridge`（新增）：store 订阅把 `auth.token` 单向同步到请求层（登录/登出/过期/rehydrate 统一经此）；`storage` 事件监听 `apex-admin:auth` 键实现多窗口同步退出（登录不同步，规格只要求退出）；接入 `main.tsx`。

### 3. 会话持久化（`authSlice`/`store`/`auth.types`）

- `AuthState` 扩展为 token/activated/user/roles/permissions/permissionsTree，全量持久化（whitelist）；**auth schema v1→v2**：模板直通登录时代的旧会话迁移为未登录态，强制真实登录重建。
- `AuthUser` 对齐真实 `UserSummary`：id（int64 字符串承载，G10）、username、state（ENABLED/DISABLED）、level、initials；显示名取用户名（后端无独立字段）；删除虚构的 email/roleNames 字段，角色码提升到会话级。
- `AuthSession` 含 token/activated/roles/permissions/permissionsTree；`AuthPermissionDto` 为权限树权威定义（T00.4 消费）。

### 4. profile 域诚实化（虚构接口移除的落点）

- Profile 页展示真实会话信息（用户名/状态/等级/角色码）；ProfileForm 改为「资料编辑暂不可用」说明（G12 缺口，P43 收口），不再发起任何请求；en-US profile/common 分片同步更新。
