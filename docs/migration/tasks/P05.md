## 控制交互样板（本页建立，设备类页面复用）

1. **可见轮询**：实时状态页用 `useVisiblePolling`，约 5 秒串行，后台页签保留快照，重新可见立即刷新。
2. **写命令三段式**：`confirmCommand`（列明对象与影响 + 「提交≠完成」固定附注）→ `verifyVehicleFresh`
   （执行前用列表同通道 pageVehicles+query 重查目标；missing=目标已不存在、stale=调度/网络状态与快照不符，
   两者都**不执行**并刷新列表让用户基于新状态重新决定——规格 8.2「影响现场的操作需先核验新状态」）→ 发命令。
3. **防连点**：行级 `pendingRowKey`（Switch/操作/删除同行禁用）、批量 `batchPending`。
4. **批量诚实反馈**：后端仅返回整批结果（ResultVoid），文案「批量指令已提交（N），执行结果以车辆状态为准」，
   不伪造逐车完成（A15；旧版「一键操作成功」已按纪律修正语义）。
5. **选择集卫生**：跨页保留；筛选提交、删除成功、批量指令成功后清理（DoD 5「失权清无效选择」）。

## 联验环境教训（沉淀给后续轮）

- 长时间联验的同一浏览器标签页在多轮 HMR + 反复 reload 后会出现渲染进程状态污染
  （表格行不渲染但 rowCount 正常、P03 页同样复现、分页器出现「第 52447 页」等荒谬值）；
  **新开标签页即恢复正常**。判定运行时行为前先换新标签页，不要急着改代码（AGENTS.md 第 5 节「重开页签」的加强版）。
- apex-table-react 列设置面板为**草稿式提交**：开关/拖动/列宽改动需点 footer「确定(Enter)」才应用并持久化，
  「恢复默认」同样需确定；header「关闭」与 Esc 为放弃草稿。页面 onColumn*Change 回调只在确定时触发一次（四切片批量）。
- IAB 的 playwright `press("Enter")` 不触发 antd Search 的 onSearch（合成事件局限），CUA keypress（真实键盘事件）可触发；
  playwright locator click 对 antd Dropdown menuitem 偶发不触发 onClick，改用 evaluate 内 element.click() 可靠。
