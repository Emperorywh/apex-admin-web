## 环境教训（本轮新增/修正，已同步 AGENTS 第 5 节）

1. **RO 垫片修正**：P39 手法（observe 时调 `this.callback`）在当前 Chrome 不可用（内部槽不再暴露，`this.callback` 为 undefined 被 try/catch 吞掉）→ 修正版在 **constructor 里捕获回调**（`this.__cb = cb`）再于 observe 后多次派发（0/60/300ms，确保布局完成后有非零尺寸回调）。探针自测 `probe-called:true` 后列表行即真实渲染。
2. **后端 root 单会话互踢**：联验期间 curl 登录会把浏览器会话踢失效（浏览器后续请求 1000000）；同理多页签并存时，幽灵页签的失效请求触发登出链路会波及新页签。联验纪律：同一时间只保持一个登录会话，API 验证与浏览器验证不混用登录。
3. **IAB Modal 关闭动画残留的老坑会叠加误导**：force-hide 残留 wrap 的内联 `style.display='none'` 会破坏 antd 后续显隐管理（open=true 也显示不出来）——清理残留后不要再复用该 Modal 实例做断言，重开页签最稳。
4. 弹窗内本地改动经 Vite HMR 热更失败时页面会进入「模块加载失败」错误边界（本轮 JSX 属性间误用 `{/* */}` 注释触发），页面级错误边界+「重试」按钮正常呈现（P42 机制实证）；语法错误修复后恢复。
