## 4. 环境教训（IAB，已同步 AGENTS 第 5 节）

- **antd Modal/confirm 的关闭动画在 IAB 冻结渲染管线不派发 animationend**：open=false 已生效（React 状态路径正确），但 DOM 卡在 `ant-zoom-leave-active` 永不隐藏；后续打开的同类型浮层实例与残留实例并存时，`.ant-modal-confirm` 类选择器会命中旧实例——点击已 resolve 的旧实例无效（P10 ⑦ 复验）。**判定关闭以 React 状态路径为准**（leave class 出现/请求计数/成功反馈），**跨调用操作浮层前先整页 reload**（reload 后 goto 返回瞬间注入垫片可同时解决 Apex 抢挂载竞态——后续轮次重载后表格渲染时好时坏的根因即垫片晚于 Apex mount，P10 ① 的 document 级变体：goto 后立即 evaluate 注入可抢在 bundle 执行前）。
