## 范围事实与口径澄清（本轮关键核对）

1. **「仅支持统计天数」为旧过时注释，不构成约束**：旧 policy.ts 与 index.tsx 注释称接口仅按天数统计，但（a）`TaskStatisticsParam` 契约为 `startTime/endTime`；（b）旧可达实现（TaskStatistics.tsx）实际渲染 TimeRangePicker 任意区间工具栏；（c）旧 repository 联调注释明示「接口支持任意起止日期与车辆筛选」。三重证据 → 本页提供任意区间选择符合契约，任务卡专项「只接受统计天数的接口不显示任意日期范围能力」按 not_applicable 登记（P35-1）。
2. **明细表语义**：旧页明细表已移除（接口无任务级明细行）；TASKS 要求「趋势与明细」「图表与 Apex 明细一致」→ 以接口真实支持的**每日聚合明细**（dailyCounts 每日一行：创建/完成/失败/取消/平均耗时）Apex data 模式交付，与任务量趋势由同一循环产出（同源同序同值，A19）。
3. **死代码不迁移**：旧 charts/TaskTypePie.tsx 仅被 import 未在 JSX 接线（类型分布接口不下发，旧页注释同口径），不迁移（AGENTS §2 递归可达纪律）。
4. **失败策略差异**：旧实现「失败仅留受控日志、保留上次数据降级展示」与现行 DoD 6（禁止旧数据冒充成功）冲突，不迁移——按 P33/P36/P37 同构 hook（失败清空+可见有限退避自动重查）交付。
5. **利用率两图只跟随统计区间**：车辆筛选仅任务统计链路消费（旧实现工具栏注释同口径），利用率排行/趋势请求不传 vehicleKeys。
