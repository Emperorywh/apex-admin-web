## 交付内容

1. **页面**（Overlook.tsx 重写）：清除模板期占位残留（console.log/硬编码 h1），改为复用 T00 统一暂缓组件 `MigrationPending`（title=调度监控）的页面级呈现；多行简体中文注释登记 D07 暂缓边界。页面无业务请求、无 WebSocket、无地图操作、无模拟停靠/充电等旧监控业务代码。
2. **路由语义（migrationDeferred 元标记，新增）**：over-look 从 `pending: true`（过渡占位、页面代码不加载）转为 `migrationDeferred: true`（本期暂缓、页面正常加载渲染）。语义区分：pending=业务实现未完成的路由占位；deferred=本期确定不迁移、已交付统一说明页。
3. **落点与回跳（routeAccess.isLeafAvailable）**：deferred 页排除出「可用业务页」——不作为登录落点候选、登录回跳不放行。理由：规格 5.6 落点=「首个有权限且已迁移完成的业务页」，说明页不是业务页；否则 root 登录落点会从 /no-permission（无可用业务页明确反馈）变成一个只有说明的页面。菜单可见性与直访守卫不受影响（仍按 OVERVIEW_VIEW 权限）。
4. **权限核对**：旧 `.umirc.ts` `/over-look` access=PERM.OVERVIEW_VIEW（overview:view）= 新 definitions.tsx businessMeta 挂码，一致未改；有权限用户菜单/直访一致可达，无权限用户守卫拦截。
5. **查询上下文保留**：直访 `/over-look?target=node-17&tab=traffic` 参数原样保留在地址栏，页面不消费、不清洗、不跳转（既不死链也不自动跳旧系统），为后续真实迁移保留上下文入口。
6. **玻璃面板修复（MigrationPending 视觉升级）**：说明文案原为 `--app-text-3` 灰字直叠全屏壁纸，深色主题下对比度不足（联验截图实证，P41 同因）；为此给组件增加内层玻璃面板（`--app-glass-window` + `--app-glass-filter` + `--app-radius-window` + `--app-window-shadow`，全部既有令牌，外层仅居中）。修复中发现并纠正 `--app-space-7` 令牌不存在导致 padding 整体失效的缺陷（改用 space-6/space-8，几何断言 hint 完全落在面板内）。
