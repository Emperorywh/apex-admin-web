## 1. 交付内容

### 服务层（owner=P16，contracts.md 第 5 节）

- `services/device-charge-pile/device-charge-pile.service.ts` + `.service.types.ts`：7 operation 逐项核对 OpenAPI 与旧实现——
  - `GET pageChargePiles`（GET+query 平铺 G04 同款：pageNo/pageSize/query）
  - `GET getChargePileDrivers`（全量，驱动下拉+驱动列名称映射数据源）
  - `POST addChargePile` / `POST updateChargePile`（ChargePileParam：deviceKey/deviceName/driverKey/deviceStatus/ip/port/deviceConfig；编辑以原 deviceKey 定位整体提交——旧实现 getFieldsValue(true) 将 setFieldsValue 存入的原 deviceKey 一并提交，表单无 deviceKey 输入框，新实现同语义显式回带）
  - `POST deleteChargePile` / `POST startCharge` / `POST stopCharge`（DeviceParam：仅 deviceKey；doorWay 为电梯前后门语义可选字段，充电桩无门体语义不携带）
- **未落地 operation（旧仓库无本页可达消费者）**：`getChargePileDetail` 旧仓库全量无引用（连 api 层均未封装）；`getAllChargePiles` 旧仓库唯一消费者为 H02 暂缓页（地图编辑器第三方设备标识选择器）——随其消费页面落地，本页列表走分页接口（P15 同纪律）。
- **契约差异（与电梯/自动门同族）**：OpenAPI **无 getChargePileState** 独立状态查询——充电桩状态随分页行记录内嵌（`deviceChargePileState.chargePileState.state`，外层 DeviceChargePileState 包内层 ChargePileState{state,statusInfo}），列表刷新即状态重查（旧实现同形态直接读行记录）；命令族仅开始/停止充电（无开关门/清占用/呼叫语义）。
