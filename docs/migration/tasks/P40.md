4. **失败清空（D15/DoD 6）**：快照接口唯一数据区域失败时快照置 null（仪表/指标卡/磁盘全部 `--`/空态）+ 徽标红「连接失败」+ 趋势脚注「连接失败，等待重试」；已采集真实趋势历史保留停止追加，恢复自动续采（旧实现同口径）；无手动刷新/重试按钮（按钮纪律）。**失败态在真实环境自然发生并取证**（root 令牌短时效）。
