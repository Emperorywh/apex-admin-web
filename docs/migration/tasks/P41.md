## 交付内容

1. **页面**（UnAccess.tsx + .module.css）：antd Result 403 等价迁移（旧同款 status/title）；主说明「无权限访问当前页面」（旧 key 沿用）+ 补充说明（联系管理员）；布局外独立全屏页（standaloneMeta，受认证守卫、非公开、无菜单码）。
2. **返回路径（防循环核心）**：返回动作不指向固定地址，按真实会话经 `resolveLandingPath`（T00 导航判断复用）计算合法落点；落点仍为本页（无任何可用业务页）时**不渲染返回入口**——页面提供的返回永不构成 /no-permission 重定向循环，也不提供绕过权限的入口（落点解析只产出当前会话有权到达的地址，A05/A22）。
3. **退出登录**：真实接口 `POST /fms/v1/auth/authorize/logout` + `sessionExpired()` 清本地会话 + replace 到登录页；接口失败不阻塞本地登出（客户端登出语义，不冒充服务端已登出），写操作不自动重试。独立页无页签草稿/传输，不涉及 guardTabAction（与旧系统直接执行一致，无确认弹窗）。
4. **状态区分**：本页只表达「无权限」一种语义；服务离线/接口缺口/本期暂缓由各业务页 StateBlock 呈现，不在本页混用。会话驻留期间被其他窗口登出时（user=null 真实状态）呈现「去登录」而非假装已登录（DoD 3）。
5. **视觉**：中央玻璃反馈面板——全局壁纸为固定照片不随主题变化，深色主题下 antd 反白文字直叠浅壁纸不可读（联验截图实证），故以 `--app-glass-window` + `--app-glass-filter` + `--app-radius-window` + `--app-window-shadow`（全部既有令牌，无第二份配色）提供两主题衬底；hint 用 `--app-text-3` + `--app-fs-secondary`。
6. **五语言**：`access-denied` 命名空间四语言分片（4 键）。en-US「无权限访问当前页面」「去登录」沿用旧系统真译；zh-TW/ja-JP/ko-KR 旧资源为简中回退，按 B1 基线交付真实译文（台湾用语：存取/登入；「退出登录」复用 common 常驻命名空间既有四语言术语，不重复定义）。路由 meta 声明 `i18nNamespaces: ['access-denied']`（common 为常驻基座无需声明）。

## 登记的限制（非缺口）
