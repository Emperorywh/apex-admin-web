## 本次完成内容

1. **页面会话层**（新增 `src/services/page-session/`）：草稿登记 store（显式登记/解除，无稿初始值不误标脏）、轻量页签状态 store（JSON 往返保证可序列化，独立于可淘汰页签实例）、统一离开协调器（保护汇总=草稿+写入 queued/running/unknown+传输 active/unknown/cancelled已发字节；确认通道；批量原子关闭；beforeunload 守卫；容量准入判定）、`usePageSession`/`useTabDrafts` Hook。
2. **页签身份规则收敛**：新增 `src/router/tabIdentity.ts`，SessionHost 页签同步与页面 Hook 共用同一解析（含对象页签 objectParam 归一）。
3. **保护性 LRU**：`tabsSlice.tabSynced` 增加 `protectedTabKeys`（宿主每次同步现算传入），受保护页签豁免淘汰；全部候选受保护时暂超容量不丢状态。
4. **批量原子关闭**：`tabsClosed(keys)` 单 dispatch 原子批量；TabsBar 右键四类批量与 Dock 废纸篓改为按当前列表取可关集合后走协调器。
5. **容量准入**：SessionHost `useBlocker` 在导航提交前判定「新建页签 + 缓存满 + 候选全受保护」，弹「页签容量已满」（留在当前页/仍要打开）；弹窗按 `blockerKey` 重建绑定当前 blocked 导航。
6. **主动退出入口**（T017 消费）：Header 退出改为 `await confirmSessionExit()`（含会话级任务）→ `logout()` → `sessionExpired()`。
7. **离开确认宿主** `LeaveGuardHost`：声明式 Modal 渲染确认队列（StrictMode 安全）、beforeunload 同步、auth.epoch 变化复位页面会话与未裁决请求。
8. **空页签兜底**（正常修复）：全部页签关闭后 SessionHost replace 回首个有权入口（`resolveFirstAccessiblePath`），不再停留无宿主空页。
9. **隔离验证 V01—V05 通过**（草稿置脏/解除、关闭取消与确认、批量原子性、写入任务执行中/待确认保护、容量准入取消/放行、跨 overlay 返回），证据见 `evidence/T013/T013-evidence.md`。
