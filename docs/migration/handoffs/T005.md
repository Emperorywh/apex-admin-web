## 本次完成内容

1. **旧身份协议接入**（替换临时直通登录与模板身份协议）：
   - `login`：密码 spark-md5（与源 `utils/crypto.ts` 逐字节兼容）→ POST `/fms/v1/auth/authorize/login`；token 按源行为以 `Bearer ` 前缀存储；快照/存储/请求头一次落库。
   - `logout`：POST logout；失败抛错保留会话（源行为），成功清存储与请求头。
   - `restoreSession`：读存储（键/形状=源 `accessInfo`）→ setLegacyToken → GET `/fms/v1/auth/authorize/detail` 重新核对身份与权限（SPEC §6.2，不只信缓存）；坏 JSON 自愈清除；1000000 立即清会话（D26）、1001000 置挂起标记、网络失败保留缓存快照（源行为对齐）。
   - `initIdentityEventBridge`：T003 事件 → 唯一身份状态（1000000 清会话每次失效仅一次；1001000 置 `authorizationRequired`）。
2. **唯一会话/权限快照**：authSlice 重构为 `{identity, epoch, restored, authorizationRequired}`；持久化仅 identity（版本升到 v2，旧模板 user 形状迁移丢弃）。权限模型纯函数：`isRootUser`（root+administrator 源判定）、双源扁平化/祖先填充/判定（菜单树、按钮集不互相兜底）、`setPermissionMenuTree` 注入点（T007 绑定 definitions）。`useAuth()` 统一消费面。
3. **移除 refresh 与认证重放**：`request.ts` 删除 accessToken 持有、`/auth/refresh` 单飞、401 刷新重放与会话派发；`request.constants` 删除 REFRESH_* 与 `API_ERROR_CODES`。新协议通道不再承载身份。
4. **切账号迟到响应隔离**：会话纪元 `getIdentityEpoch/isIdentityEpochCurrent`；`identityVerified` 仅纪元匹配生效；sessionExpired/identityReady 推进纪元。
5. **配套（不另拆卡）**：LoginForm 激活分流（activated===false → authorize-ingress）并去掉源没有的用户名长度约束；Header 头像/退出适配（登出失败保留会话并提示）；Profile 页改为身份快照只读展示（D07 不纳入资料编辑，删除死亡的新协议 profile 服务与表单）；新增词条 en-US（五语补齐归 T016）。
