# 项目定位与开发规范

## 1. 核心原则

- 本项目定位为面向外部开发者的开源 React 表格组件库。所有设计、开发、重构、文档、验证和发布工作，都必须以开源组件库的可复用性、可维护性和长期兼容性为标准。
- 从组件库使用者的角度评估改动：接入应简单，行为应可预测，类型应清晰，扩展应有明确边界。不能仅以当前演示页面能够运行作为完成标准。
- 通用能力进入组件库，具体业务流程、接口请求、权限规则、路由和业务数据留在消费项目或示例中；不得为了单个示例将业务逻辑写入组件内部。
- 在既有架构和公开能力边界内实现需求，不为假想场景引入无关抽象、依赖或功能。尚未实现或验证的能力不得对外承诺。
